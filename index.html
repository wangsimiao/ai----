商品替换

把旧商品图快速变成新商品场景图，适合大促、上新和临时改图。

输入提示词

保留场景真实感，替换为目标商品，保持光影、材质和比例自然。

输入素材
OUTPUT / 商品替换候选原图比例

讲替换不是贴图，重点是光影和比例一致。

画芯替换

把目标画芯放进商品结构里，快速生成多方向候选。

输入提示词

将目标画芯自然替换到商品中，保持透视、边缘和材质一致。

输入素材
OUTPUT / 画芯替换候选原图比例

重点讲边缘、透视和花型比例。

人物融合

人物、商品和场景自然融合，用来补充种草图和情绪图。

输入提示词

让人物和商品自然融合，保持光影统一、比例真实，不要明显 AI 痕迹。

输入素材
OUTPUT / 人物融合候选原图比例

人物相关要强调自然和风险边界。

买家秀

不是精修海报，而是更像真实使用场景的内容补图。

输入提示词

生成自然生活感买家秀，保留商品真实细节，避免过度精修。

输入素材
OUTPUT / 买家秀候选原图比例

强调真实感和业务可用之间的平衡。

瑕疵修复

小问题别拖成大返工，先局部修复，不必整张重跑。

输入提示词

去除水印、修复局部穿帮，并保持材质和花型连续。

输入素材
OUTPUT / 修复后候选原图比例

不是所有图都救，能交付的候选才进入修复。

高清放大

小图别硬撑大场面，需要高清放大后用于详情页和投放。

输入提示词

高清放大这张候选图，增强布料纹理和细节，不改变构图和商品样式。

输入素材
OUTPUT / 高清交付图原图比例

方向不对的图先别放大。

扩图

画面不够完整时，把现有商品图或场景图向外延展。

输入提示词

在不改变商品主体、材质和画面风格的前提下，向外扩展画面。

输入素材
OUTPUT / 扩图候选原图比例

扩图重点讲“保持一致”。

多角度图

围绕同一商品生成正面、侧面、细节和使用场景等多角度素材。

输入提示词

基于同一商品，生成多角度展示图，保持颜色、材质、花型和比例一致。

输入素材
OUTPUT / 多角度候选原图比例

重点讲“一致性”：同一个商品不能每张都变样。
