瑕疵修复

输入提示词

输入素材
OUTPUT / 修复后候选完整展示

高清放大

输入提示词

输入素材
OUTPUT / 高清交付图完整展示

方向不对的图先别放大。

扩图

画面不够完整时，把现有商品图或场景图向外延展。

输入提示词

在不改变商品主体、材质和画面风格的前提下，向外扩展画面。

输入素材
OUTPUT / 扩图候选完整展示

扩图重点讲“保持一致”。

输入素材
OUTPUT / 多角度候选完整展示
